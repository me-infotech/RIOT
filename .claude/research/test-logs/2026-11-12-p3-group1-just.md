## Forward contract (final)

- The Make declaration keeps the original prerequisite graph where it
  consisted of other Make targets or input files (`doc/starlight`: `build:
  install`, `preview: build`, `dev: install`, `integrate_outside_files:` the
  copy targets, each copy target its Markdown source; `doc/doxygen`: the
  inputs of `src/changelog.md`). just runs only the target's own step
  (`_starlight-*-step`, `starlight-<copy target>`), so `make -k/-i/-j` behave
  as before.
- All doc/doxygen goals of one make run go to one `just _doxygen-goals`
  call; just runs each step once, like Make's shared prerequisites.
- Only user values reach just; `BOARDS` exported by `export BOARDS ?=` in
  `app_dirs.inc.mk` is dropped for `info-boards` (`env -u`). Other root
  forwards still inherit that export, but no recipe reads `BOARDS`.
